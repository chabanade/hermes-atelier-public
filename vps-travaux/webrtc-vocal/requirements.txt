aiohttp
aiortc
numpy

# --- STT + TTS (sous-processus, même venv) -----------------------------------
# faster-whisper : transcription (modèle whisper en cache sous models/hf/).
# piper-tts      : synthèse vocale (voix .onnx sous models/piper/).
# server.py les lance via transcribe.py / synth.py ; le préflight de server.py
# vérifie au démarrage qu'ils sont bien importables, sinon il refuse de démarrer.
faster-whisper
piper-tts

# --- VAD (détection d'activité vocale), tourne en local, sans GPU ------------
# Backend choisi automatiquement par server.py : silero -> webrtcvad -> énergie.
#
# webrtcvad : léger et robuste. Le paquet « webrtcvad » se compile (en-têtes
# python3-dev requis) ; « webrtcvad-wheels » fournit des roues précompilées
# (aucune compilation) — recommandé.
webrtcvad-wheels

# Optionnel — VAD neuronal (meilleure qualité, plus lourd : tire torch). S'il est

# silero-vad
